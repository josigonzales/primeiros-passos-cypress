# Cypress Automation

This project utilizes Cypress to automate the test of a login feature and user update feature.
Cypress is a JavaScript-based end-to-end testing framework taht allows developers to write tests and execute them in a real browser.

## Installation

``` bash

npm install

```

> **NOTE:**
>
> it is necessary to have **node** installed

## Running

``` bash
# You open the Cypress UI
npx cypress open

# Run the automatic by command line
npx cypress run
```
